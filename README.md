# Professional Book Shop System v3

Website-first Book Shop system with a secure-looking admin login, book/product management, barcode/POS billing, customers, stock, expenses, reports, settings, local backup, and one-page invoice printing.

Demo admin credentials: admin / admin123

Important: this GitHub Pages version is client-side and stores data in the browser localStorage. The password is not secure for production because the page source is public. A production deployment should use a backend authentication/database service.
